# Family Expenses

Сервис для учёта семейных расходов: Telegram-бот с LLM и веб-панель администратора.

## Возможности

- **Telegram-бот:** добавление, просмотр, изменение и удаление своих расходов на естественном языке. Каждый пользователь работает только со своими записями.
- **Веб-панель:** просмотр и CRUD расходов всех пользователей, фильтрация по Telegram ID, категории и периоду.
- **REST API:** управление расходами через HTTP.

## Технологии

Go (Echo, sqlx), PostgreSQL, Telegram Bot API, OpenRouter, HTML/CSS/JavaScript, Docker Compose.

## Запуск

1. Создайте файл `.env` на основе `.env.example` и укажите свои `TG_API_KEY` и `LLM_API_KEY`.
   - `TG_API_KEY` - ключ от Вашего бота. Создайте его с помощью @BotFather
   - `LLM_API_KEY` - ключ от OpenRouter. Получите его при регистрации
2. Запустите приложение:

   ```bash
   docker compose up --build
   ```

3. Откройте веб-панель: **http://localhost:8080**.
4. Найдите своего Telegram-бота и отправьте ему сообщение.

Миграции базы данных применяются автоматически при запуске приложения.

## Примеры сообщений боту

- `Кофе 350`
- `Такси 1200 вчера`
- `Покажи расходы за неделю`
- `Последняя трата была не 350, а 450`
- `Удали последнюю трату`

## REST API

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/expenses` | Список расходов с фильтрами |
| `GET` | `/expenses/users` | Telegram ID пользователей |
| `POST` | `/expenses` | Создать расход |
| `PUT` | `/expenses/:id` | Изменить расход |
| `DELETE` | `/expenses/:id` | Удалить расход |

Параметры фильтрации для `GET /expenses`: `user_id`, `category`, `from`, `to` (даты в формате `YYYY-MM-DD`).
